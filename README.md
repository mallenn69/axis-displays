# Axis Displays

LED display website design with a looping video hero, interactive Pro X2 panel, photography gallery and inquiry form.

**Live design preview:** https://mallenn69.github.io/axis-displays/

The GitHub Pages version is for design review. Quote submission and admin require server hosting and are disabled or excluded from this preview. Product specifications and naming are provisional.

## Development

- `npm ci`
- `npm run dev` — full application; current landing design at `/concept`
- `npm run build:preview` — standalone GitHub Pages build
- `npm run build` — full server application
- `npm test` — application tests

See [PREVIEW.md](PREVIEW.md) for deployment notes. Backend configuration belongs in local environment files, which are excluded from version control.

Based on the original [Axis Glow project](https://github.com/mallenn69/axis-glow). This separate repository does not modify that project's history.
